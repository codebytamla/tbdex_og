Auth · Public

No JWT required.

GET /health Public

Health probe.

200 {"status":"ok"}
POST /auth/login Public

Authenticate by email/password. Returns user + token pair.

Request

  • Body: { email, password }
  • Header (optional): X-Device-Name

Response 200

  • { user, tokens: { access_token, refresh_token, expires_in } }
200 400 invalid body 401 invalid credentials 500
POST /auth/refresh Public

Rotate refresh token. Issues new access + refresh pair.

Request

  • Body: { refresh_token }

Response 200

  • { access_token, refresh_token, expires_in }
200 400 missing token 401 invalid / expired 500
POST /auth/logout Public

Revoke a refresh token (idempotent).

Request

  • Body: { refresh_token }

Response 200

  • { "status": "ok" }
200 400 500
POST /auth/forgot-password Public

Generate password reset token. Always 200 to prevent email enumeration.

Request

  • Body: { email }

Response 200

  • { "status": "ok", "reset_token": "..." }
  • reset_token included in dev mode only
200 400 500
POST /auth/reset-password Public

Reset password using token. Revokes all refresh sessions.

Request

  • Body: { token, new_password }
  • new_password min 8 chars

Response 200

  • { "status": "ok" }
200 400 bad token / weak password 500

Admin · Users

User CRUD, role/site assignment, password reset, enable/disable.

POST /admin/users Bearer users.create

Create a user. Optionally assign roles and sites.

Request

  • Body: { email, full_name, password?, roles?, sites? }
  • If password omitted, a random one is generated and reset_token returned

Response 201

  • { user, reset_token? }
201 400 / 409 exists 403 500
GET /admin/users Bearer users.read

List users with cursor pagination and filters.

Query Params

  • limit — page size (default 50, max 100)
  • cursor — opaque next-page token
  • search — match email or full_name
  • is_active — true | false
  • role — repeatable, e.g. role=ADMIN&role=DOCTOR
  • site_id — repeatable UUID
  • include_total — true | false

Response 200

  • { users[], pagination: { next_cursor, has_next, limit }, total? }
200 400 bad params 403 500

Patients

Patient registration, lookup, update, and deactivation. All mutations use database transactions.

POST /patients Bearer patients.create

Register a new patient. created_by is set to the authenticated user.

Request

  • Body (required): full_name
  • Body (optional): date_of_birth (YYYY-MM-DD), is_dob_estimated, sex (male|female|other), phone, national_id, mrn, address, village, origin, status (provisional|active|inactive|deceased)

Response 201

  • Patient object with all fields
  • mrn is immutable once set (DB trigger enforced)
201 400 missing fields / invalid status 409 duplicate national_id or mrn 500
Example Request 
{
  "full_name": "Amina Hassan",
  "date_of_birth": "1990-03-15",
  "sex": "female",
  "phone": "+254700000000",
  "national_id": "NAT-12345",
  "address": "Nairobi, Kenya",
  "village": "Kawangware",
  "status": "active"
}
GET /patients Bearer patients.read

List patients with cursor-based pagination.

Query Params

  • limit — page size (default 50, max 100)
  • cursor — opaque next-page token from previous response
  • search — match full_name, mrn, or national_id
  • status — provisional | active | inactive | deceased
  • include_total — true | false

Response 200

  • { patients[], has_next, next_cursor?, total? }
200 400 bad cursor / params 500

PATCH /patients/{id} Bearer patients.update

Update patient fields. Only provided fields are changed (COALESCE). mrn cannot be changed once set.

Request

  • Body (all optional): full_name, date_of_birth, is_dob_estimated, sex, phone, national_id, address, village, origin, status

Response 200

  • Updated patient object
200 400 invalid status 404 not found 409 duplicate national_id 500
POST /patients/{id}/disable Bearer

Disable a patient (sets status = inactive). Only the ADMIN role or the user who created the patient can call this. No permission middleware — authorization is checked in the service layer.

Response 200

  • Updated patient object with status: "inactive"
200 400 bad id 403 not admin or creator 404 not found 500
