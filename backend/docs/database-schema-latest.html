Relationship Summary

  • users many-to-many sites via user_sites.
  • users many-to-many roles via user_roles.
  • roles many-to-many permissions via role_permissions.
  • users one-to-many refresh_tokens, password_reset_tokens.
  • audit_events references users through actor_id and target_id.
  • patients optionally references users through created_by.
